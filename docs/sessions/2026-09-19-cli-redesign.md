# CLI redesign implementation: 2026-09-19

## Scope and isolation

Implemented on `feat/cli-redesign-20260919`, based on `1ac8e628c`, in the isolated Macpoo worktree `cli-redesign-20260919`. No installed binary, gateway configuration, credential store, native update job, or production service was changed. The unrelated original checkout was left untouched.

## Implemented

The public grammar now centers on `server`, `route`, `loadout`, `auth`, `host`, `plugin`, `config`, `code`, `snippet`, and `skill`. Public names and aliases contain no hyphens. Existing operation handlers, authority rules, action identifiers, and patch/replacement semantics are reused through typed command lowering.

Root help is the actual Clap CLI instead of an intercepted MCP action catalog. Complete, subtree, search, JSON, generated Markdown, and completion discovery share the same command graph. The all-feature inventory contains 163 public paths across 20 root groups. Retired prefixes produce migration advice, not executable hidden aliases.

Diagnostics preserve typed errors and report command path, origin, side effects, recovery guidance, and runtime request ID. JSON failures stay one envelope on stderr even when console verbosity is enabled. Quiet/disabled logging does not suppress human errors. Structured operation logs contain duration, correlation, and outcome metadata without raw arguments or payloads. Log-directory failures degrade without panicking or corrupting JSON.

Dry-run output is redacted and structured. Code Mode supports typed search/describe commands and bounded source-file/stdin input. A failed remote execution can no longer replay through the local broker. `logs` is a bounded, filtered local rolling-log query; deployment journals and streaming are explicit.

Maintained documentation, plugin instructions, copied UI commands, shell consumers, native schedule generation, and action fixtures have been migrated. Historical documents remain untouched. Previous-release qualification scripts select their grammar through read-only help before any mutation rather than retrying failed mutations through another spelling.

## Validation evidence

The initial seven executable contracts failed against the baseline before implementation. Subsequent local runs passed 173 CLI unit tests, seven entrypoint tests, 21 documentation tests, 27 self-update tests, 16 executable CLI contracts, 10 isolated remote-routing tests, 68 setup/proxy/support tests (eight intentionally ignored), and two startup-configuration tests. The release-hardening Python suite passed 73 tests with four platform-specific skips when invoked from the repository root.

All-feature documentation generation/check covers 19 artifacts. The public-path contract runs `--help` against every advertised command with deliberately invalid installation configuration. Additional tests verify raw-argument redaction, request-ID log lookup, unwritable log directories, uncertain remote outcomes, and the preserved typed operation mappings. Reduced builds without default features, with skills only, and with gateway only compile; feature-reduced configurations emit unrelated dead-code/unused warnings. Default-feature library/binary Clippy passes with warnings denied.

The development build warns that embedded gateway-admin web assets are absent, and the macOS linker warns about a large unwind section. This is not a production deployment artifact or a completed cross-platform release qualification.

## Release boundary and remaining work

This is a breaking command-grammar change. No merge or deployment was performed. GitHub schema discovery for PR creation failed, and Macpoo's GitHub CLI returned HTTP 401; credentials were not modified.

Before rollout, update external script consumers and completion installations. Existing native update schedules generated by an older binary must be refreshed using `labby host update auto enable`; new schedules use `labby host update --automatic`. Existing host-and-Incus update behavior and explicit provider-wide revocation remain unchanged.

Named connection contexts, guided interactive upstream creation, cached resource-name completions, standardized duration operands, and a redesigned lifecycle wait/bulk/idempotency contract are follow-up work. They are not implied by this grammar migration and must preserve existing caller authority and retry safety.
