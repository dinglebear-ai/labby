# Reflection

Review method: direct self-review plus executable unit/integration, documentation, and live runtime checks. No independent reviewer or excluded agent was invoked.

A process is not proven by its final prose. The original marker commit and static health file demonstrated individual mechanics, not a published application. The new contract distinguishes receipt consistency, observed remote publication, artifact identity, actual sandbox configuration, and external health.

Adapter/runtime versions and authentication paths are separate axes. Diagnose them independently instead of replacing a working host runtime or copying credentials into the guest. A full Git publication broker can preserve isolation without claiming in-VM authentication.

Keep external post-commit evidence separate from the source tree. Preserve failed runs and limitations, and never count a fixture as a product test.

The reference bootstrap pins package versions but does not archive package repositories. Long-lived reproduction should publish the prepared image by digest with retained provenance.
