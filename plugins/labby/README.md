# labby

Skills for an existing Labby gateway: `using-labby`, `using-codemode`, `using-snippets`, and [implement-in-microsandbox](skills/implement-in-microsandbox/SKILL.md). This plugin does not register an MCP server. Install `install-labby` for the guided installation skill and the `lab` HTTP MCP connection.

Labby server configuration remains owned by the Labby binary, Settings UI, and setup CLI. No Claude Code lifecycle hooks are shipped.
